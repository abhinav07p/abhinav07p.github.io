Enterprise AI Readiness Intelligence Platform

PE Org-AI-R: AI due diligence for private equity

A data and agent platform that tells private equity firms how AI-ready a target company really is. It pulls signals from SEC filings, patents, job postings, and employee reviews, computes a multi-dimensional Org-AI-R score, and turns the evidence into citation-backed investment memos with a Buy / Hold / Pass recommendation. Case Study 4 added the RAG engine. Case Study 5 added the multi-agent workflow, MCP server, ROI analytics, and observability.

The problem it solves

Assessing a target’s AI maturity usually means analysts reading filings, scanning job boards, and writing memos by hand.

Collect

Airflow pipelines gather signals from SEC filings, PatentsView, job postings, Glassdoor, company websites, and leadership data, with rate limiting, retries, and graceful degradation.

Score

A scoring engine combines dimension signals (V^R, H^R, Synergy, confidence) into one Org-AI-R score, with per-dimension evidence kept for audit.

Justify and decide

A hybrid RAG layer and a LangGraph agent workflow turn evidence into IC memos and LP letters, and pause for a human when the score falls below a threshold.

System architecture

Everything sits behind one Nginx entry point. Airflow acts as a worker pool, and the MCP server runs as its own container so Claude Desktop can connect independently of the main API.

Nine-container Docker Compose stack: Nginx, FastAPI, Next.js, MCP server, Airflow webserver / scheduler / triggerer, Postgres, and Redis.

Agentic due diligence

A LangGraph StateGraph replaces ad-hoc API calls with a typed, auditable pipeline over a shared DueDiligenceState.

SEC Analyst→Scorer→Evidence Agent→Value Creator*→HITL check

* skipped in Quick mode.

NodeResponsibility
SEC AnalystFetches and analyzes SEC filing signals for the target
ScorerCalls the scoring engine for Org-AI-R, V^R, H^R, and Synergy
Evidence AgentRetrieves signals and writes RAG-backed dimension justifications
Value CreatorGap analysis, EBITDA impact projection, and a 100-day value creation plan
HITL checkPauses the workflow when Org-AI-R is below the threshold (default 60) and sets approval_status = pending for analyst review

Full mode

All five nodes, including gap analysis and EBITDA projection. About 60–120 seconds.

Quick mode

Skips the Value Creator and returns scores plus evidence. About 20–40 seconds.

Hybrid RAG and the IC package

Pure vector search misses exact technical terms, and pure BM25 misses paraphrases. The platform uses both.

Hybrid retrieval

ChromaDB dense search (weight 0.6) and BM25 sparse search (weight 0.4) fused with Reciprocal Rank Fusion. Each document is tagged with its OrgAIR dimension for filtered retrieval, and optional HyDE expands abstract queries before embedding.

Score justification

The generator writes roughly 150-word PE-style memos per dimension with inline [N] citations and one identified gap sentence.

IC Meeting Package

POST /justify retrieves evidence for all seven dimensions concurrently, recomputes the scores, and synthesizes strengths, gaps, risks, and a Buy / Hold / Pass recommendation as a structured package.

Analyst notes

Interview transcripts and data-room findings can be ingested manually and become searchable alongside automated signals at a 0.9 confidence weight.

Pipeline resilience

Built to survive rate limits, blocked scrapers, and heavy payloads.

ConcernHow it is handled
Per-company parallelismDynamic Task Mapping (.expand()) with one isolated MappedTaskGroup per company
Partial failuresTriggerRule.ALL_DONE: if the Glassdoor scraper is rate-limited, SEC and patent analysis still finish and a partial score is computed with a lower confidence
Heavy payloads10-K chunks go to a shared Docker volume instead of XCom, keeping the Airflow metadata DB fast
API quotasAsyncRateLimiter capped at 45 requests a minute for PatentsView, spacing between SEC and job requests, Tenacity exponential backoff
Bot detectionPlaywright with stealth mode and User-Agent rotation, falling back to job-description keyword analysis if a site blocks the scan
Concurrencyasyncio.Semaphore(5) to protect Snowflake connections, and a thread pool for parsing 50 MB filings so the event loop stays responsive

Key design decisions

Single source of truth

Legacy tables were consolidated into one companies schema so the SEC pipeline can anchor discovered CIKs to existing targets.

Snowflake singleton

A thread-safe connection manager with a persistent session pool avoids the SSL handshake on every request.

Graceful degradation

Missing S3 or PatentsView credentials log a warning and the rest of the platform keeps serving.

MCP as a separate container

Keeps the tool gateway independent of the main API and lets the bridge handle stdio-to-SSE translation for Claude Desktop.

LangGraph over ad-hoc calls

Typed shared state, conditional edges for Full and Quick modes without duplicating agent logic, and a human-in-the-loop interrupt.

LiteLLM routing

Swapping models is a routing-table change, not a code rewrite.

Known limitations

In-memory state

The BM25 index and Prometheus counters reset on container restart, so evidence must be re-ingested to restore the hybrid index.

Source quotas

Glassdoor and site scans are rate-limited or occasionally blocked. Reviews are cached in S3 and the scoring degrades to partial confidence instead of failing.
